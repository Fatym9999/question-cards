# Дизайн приложения «Карточки с вопросами в пушах»

Источник правды по виду: файл `screens.html` (все экраны, готовая разметка и стили). Этот файл описывает правила. При расхождении ориентируйся на `screens.html`.

## Общее
- Только светлая тема. Темную тему не делать. Строку «Тема» в настройках в MVP не реализовывать.
- Mobile-first, ширина макета 390 px. На широких экранах контент по центру, max-width 480 px.
- Интерфейс на русском. Кавычки «ёлочки», апостроф ’.
- Учитывать safe-area iPhone (env(safe-area-inset-*)), viewport-fit=cover.
- Минимум анимаций. Уважать prefers-reduced-motion.

## Токены
Цвета:
- фон страницы `#F1EEE9`
- основной текст/чернила `#2B2622`
- вторичный текст `#6A6259`
- акцент-декор (полоска над вопросом, размытые пятна на фоне) `#D97757`
- акцент для текстовых ссылок (например «Показать ответ») `#A9502F`
- линии/рамки карточек `#E4DFD6`, рамки кнопок `#D6D0C6`
- карточка: `rgba(255,255,255,0.6)` + рамка `#E4DFD6`
- бейдж «к повторению»: фон `#F3DCCF`, текст `#8A3F23`
- переключатель: включён `#2B2622`, выключен `#A39B8E`, ползунок белый
- второе размытое пятно на фоне `#C99A3A` с opacity 0.18

Шрифты (Google Fonts, есть кириллица):
- Lora 500: заголовки и текст вопроса (34 px, line-height 1.25, letter-spacing -0.01em)
- Manrope 400/500/600: весь остальной интерфейс. Основной текст 16–17 px, вторичный 13–14 px.

Радиусы: карточки 20, кнопки оценки 16, главная кнопка 16–18, плавающая панель 34, «таблетки» 22, переключатель 16.

Размытое фоновое пятно: два абсолютно позиционированных круга внизу фона (280 px `#D97757` opacity 0.3 blur 34 px и 200 px `#C99A3A` opacity 0.18 blur 30 px). Они нужны, чтобы эффект стекла нижней панели был виден.

## Нижняя панель (Liquid Glass)
- Плавающая, `position: absolute/fixed`, отступы 20 px по бокам, 28 px снизу (плюс safe-area).
- Высота 68, радиус 34, фон `rgba(255,255,255,0.5)`, `backdrop-filter: blur(22px) saturate(1.6)` (и -webkit-), рамка `1px rgba(255,255,255,0.75)`, тень `0 8px 28px rgba(43,38,34,0.14)` и `inset 0 1px 0 rgba(255,255,255,0.9)`.
- Три вкладки: «Учить», «Колоды», «Настройки». Иконка 24 px (линия 1.5, скругления round) над подписью 12 px.
- Активная вкладка: фон `rgba(255,255,255,0.85)`, лёгкая тень, подпись 600. Неактивные: цвет `#5C554C`.
- Внизу каждого экрана отступ 112 px, чтобы контент не уходил под панель.

## Экраны
1. **Учить · вопрос.** Сверху слева название колоды (14 px, вторичный цвет), справа счётчик «2 / 6». По центру: короткая полоска акцента, вопрос (Lora). Сразу под вопросом ссылка «Показать ответ» с шевроном вниз. Внизу три кнопки в ряд: «Не знаю», «Сложно», «Знаю» (последняя залита чернилами). Кнопки видны всегда. Любая оценка («Не знаю», «Сложно», «Знаю») сразу открывает следующую карточку, без промежуточных экранов и подтверждений. Никаких подписей про интервалы («10 мин», «1 дн.») не показывать.
2. **Учить · ответ открыт.** Вместо ссылки под вопросом блок с ответом (карточка, 17 px). Оценочные кнопки те же.
3. **Учить · всё повторено.** По центру галочка в круге, «На сегодня всё», пояснение «Следующий вопрос придёт в уведомлении», кнопка «Добавить карточки».
4. **Колоды.** Заголовок и подпись («3 колоды · 28 карточек»). Карточки колод: название, «12 карточек», справа бейдж с числом к повторению или «Повторено». Внизу «Новая колода» (пунктирная рамка).
5. **Колода.** Кнопка назад и «+ Карточка» в стеклянных «таблетках», заголовок, «Начать повторение», фильтры-чипы «Все / Новые / К повторению / Избранные» с числами, список карточек со звёздочкой избранного (44 px зона нажатия).
6. **Настройки.** Группы-карточки: «Уведомления» (с кратким состоянием), «Установка на телефон» (инструкция «На экран Домой», нужна для пушей на iPhone), «Тема» (в MVP не делать), «Аккаунт» (почта и «Выйти»).
7. **Уведомления.** Переключатель «Вопросы в уведомлениях» с описанием («5 раз в день, с 9:00 до 20:00»). Пресеты «Обычный / Вечер / Интенсив / Свой». Число уведомлений в день (кнопки − и + по 44 px), «Начало», «Конец» (выбор времени), «Не беспокоить» с интервалом и переключателем. «Колоды для уведомлений» с переключателем у каждой. Внизу ссылка «Отправить тестовое уведомление».

## Поведение
- Любая оценка сразу переключает на следующую карточку, дополнительных экранов нет.
- Интервалы повторения пользователю не показываются. Их считает алгоритм.
- Нажатие на push открывает экран «Учить» именно с этой карточкой (вопрос, без ответа).
- Все переключатели: `<button role="switch" aria-checked>`; иконочные кнопки с `aria-label`.
- Размер зон нажатия не менее 44 px. Контраст текста не ниже 4.5:1.
- Названия колод, карточки и числа в макете примерные.
